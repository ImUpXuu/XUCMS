# Upxuu Editor

Upxuu Editor 是一款精美的 Android 客户端，让你能随时随地写作、管理你的文章和动态说说。

## 功能介绍

- 支持文章和说说（动态）的编写
- Markdown 语法高亮和可视化排版支持
- 图片上传与图库管理
- 文章缓存和意外退出自动恢复
- 浅色/深色主题模式跟随系统或自主切换
- 自定义配置 API 服务器
- 应用安全隔离存储 Token 和配置数据
- 支持多端使用，GitHub Actions 自动化 CI 构建

## 构建与运行

在本地 clone 项目后，使用 Android Studio 等工具打开，通过 Gradle 进行构建即可运行。也可以在发布页面下载自动构建的 APK。

感谢使用！
